Cloud Tasks · API key required

Each email becomes a task with up to 3 attempts (exponential backoff). A third failure lands in the dead-letter queue with its reason and original input, from where it can be retried. The demo batch below sends one healthy email, one that fails twice then succeeds (fail_times=2), and one that fails every time (fail_times=99).
